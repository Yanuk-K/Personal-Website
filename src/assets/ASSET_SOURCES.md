# Icon and Image Sources

- **Coffee app icon** — derived from KDE Breeze `kteatime.svg`
  (LGPL-3.0), with the tea tag/string removed and the drink recoloured to
  coffee. Source: https://github.com/KDE/breeze-icons
- **Coffee grinder icon** — "Kitchen Icon - Coffee Grinder" by StudioFibonacci,
  Openclipart, public domain (CC0). Used by the Grinder view in the Coffee app. Source:
  https://openclipart.org/detail/169935/kitchen-icon---coffee-grinder-by-studiofibonacci
- **Papirus app icons** (`src/assets/papirus/`) — Papirus icon theme,
  GPL-3.0. Source: https://github.com/PapirusDevelopmentTeam/papirus-icon-theme
- **Wallpapers** — NASA imagery, public domain; see `WALLPAPER_SOURCES.md`.
